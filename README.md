# Project Zomboid Server Admin Scripts

Automated maintenance, supply drops, and mod management scripts for self-hosted [Project Zomboid](https://github.com/indifferentbroccoli/projectzomboid-server-docker) Docker servers. 

Designed for low-overhead server administration without relying on third-party panel tools. Originally built for the PaymoneyWubby Wubcord Community Server.

---

## Caretaking (`caretaking.sh`)
Automated maintenance manager that checks for stale mods and player activity before initiating server updates. 

* **Mod Update Detection:** Monitors server logs via RCON to detect when Workshop mods are flagged as "need update".
* **Smart Player Detection:** Checks online player counts via RCON before taking action.
* **Quiet Hours:** Prevents automated restarts during configurable prime-time hours, deferring updates until the server is less active.
* **Dynamic Warning System:** Issues an RCON `servermsg` warning players to find safety (30–90 second delay based on player count, plus a 30-second final warning).
* **Graceful Restarts:** Triggers an RCON `save` and `quit`. Relies on Docker Compose `restart: always` to pull updates and launch instantly.
* **Health Verification:** Waits up to 300 seconds post-restart to confirm the server is back online and RCON is answering.
* **Logging & Housekeeping:** Output is appended to a dedicated `.log` file, and automatically prunes old Zomboid logs and dangling Docker images.

---

## Supply Drops (`supplydrop.sh`)
An automated event script that delivers randomized, weighted loot directly to active players.

* **Weighted RNG Distribution:** Performs a weighted random selection using `pz-pool.txt` to deliver up to 3 items per player.
* **Custom Pool (`pz-pool.txt`):** Supports custom loot tables generated by the server admin with specific drop weights.
* **Immersive Broadcasts:** Announces drops using randomized event messages (e.g., crashing planes, drones, sonic booms) or broadcasts specific player rewards.
* **Cooldown Engine:** Randomizes the next drop window between a configurable minimum and maximum hours (e.g., 2–6 hours) to prevent predictable farming.
* **Testing & Verification Tools:** Includes an `--odds` flag to simulate drop distributions and a `--verify` flag to spawn the entire pool into an admin's inventory to catch invalid item IDs.

## Events
Alter your world in ways to make special events active, then return to your previous settings, automatically. Many examples included, which are live on my server.

## Prerequisites

* Linux host environment
* Docker & Docker Compose setup using the [Indifferent Broccoli image](https://github.com/indifferentbroccoli/projectzomboid-server-docker)
* RCON enabled on the target Project Zomboid instance
* Python 3 installed within the container (for RCON bridging and manifest parsing)
* `cron` utility enabled on the host OS
